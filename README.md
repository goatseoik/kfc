# 한방 격투

브라우저에서 바로 하는 3D 종합격투 게임. `index.html`을 웹 서버(GitHub Pages 등)로 열면 된다.

- 조작: 조이스틱/WASD 이동, J 잽, K 스트레이트, L 보디훅, I 킥, 스페이스 가드, U 스텝, O 필살기, T 도발, C 시점
- 퍼펙트 가드: 맞기 직전에 가드를 올리면 피해 없이 막고 상대가 휘청인다
- 필살기: 때리고 맞고 막으면 게이지가 찬다. 다 차면 고른 선수의 필살기가 나간다
- 연타: 끊기지 않고 계속 맞히면 연타 수가 올라간다
- 투혼: 체력이 4분의 1 아래면 주먹이 20% 세지고 필살기 게이지가 빨리 찬다
- 철창 쾅: 철창 가까이 있는 상대를 때리면 부딪혀서 피해를 더 입는다
- 도발: 춤을 끝까지 추면 필살기 게이지가 크게 찬다. 추는 동안 맞으면 더 아프다
- 숨은 4차전: 챔피언을 이기면 네 가지 필살기를 다 쓰는 상대가 나타난다
- 경기장 고르기(첫 화면 '경기장'): 기본 옥타곤 / 대형 경기장(훨씬 넓다). 친구 대전은 먼저 방에 들어간 사람(방장)의 경기장으로 싸운다
- 선수 고르기(첫 화면 '내 선수'): 이한방 슈퍼맨 펀치 / 오만득 슬라이딩 태클 / 강번개 번개 연타 / 한태산 회오리 연타. 능력치는 같고 생김새와 필살기만 다르다
- 혼자 하기: 세 명을 차례로 꺾는 3라운드 경기
- 친구 대전: 같은 방 번호(4자리)를 넣으면 일대일로 붙는다 (PeerJS 무료 연결 서버 사용, 둘 다 이 페이지를 열어 둬야 함)

## 에셋

선수 모델과 동작은 Quaternius의 Universal Base Characters, Universal Animation Library 1·2 (CC0)를 가공해 썼다.
`fighter.txt`, `a1.txt`, `a2.txt`는 GLB 파일을 base64 글자로 바꾼 것이다.
